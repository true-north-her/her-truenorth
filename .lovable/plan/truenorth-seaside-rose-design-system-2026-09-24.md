# TrueNorth Seaside Rose Design System

## Goal
Create a reusable brand system around the supplied compass logo, seaside rose imagery, and official palette, then apply it to the current landing page without changing its content structure, links, or smooth-scrolling behavior.

## Build
- Define semantic color, typography, spacing, radius, shadow, motion, container, form, and interaction tokens in the global stylesheet.
- Load Libre Baskerville and DM Sans; use a graceful Corsiva-style script fallback for sparse decorative accents.
- Add reusable brand primitives for the logo, editorial labels, compass dividers, surfaces, form fields, and badges.
- Refine all button variants to the official primary, secondary, and ghost treatments with accessible focus states.
- Apply the system consistently to navigation, video opening, editorial chapters, community moments, growth loop, Founding Circle, and footer.
- Use the supplied primary logo without distortion and update the favicon from the same mark.
- Integrate the supplied rose-by-the-sea photograph as a restrained editorial visual, using the uploaded imagery rather than stock assets.
- Preserve current copy, anchors, external links, animations, Lenis behavior, and mobile-native scrolling.

## Responsive and Accessibility
- Keep desktop compositions spacious and asymmetric while simplifying decorative treatments on mobile.
- Maintain readable contrast, semantic headings, keyboard focus, touch-friendly controls, and reduced-motion behavior.
- Verify desktop and mobile layouts, video/poster behavior, navigation anchors, external links, overflow, and browser errors.
